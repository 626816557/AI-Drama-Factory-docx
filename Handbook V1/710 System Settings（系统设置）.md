# 一、本文档回答什么问题？

本文档回答：

> **AI Drama Factory 应如何统一治理整个 Factory 的全局规则（Factory Governance）？**

System Settings（系统设置）。

负责统一管理：

Factory 的全局配置。

组织策略。

权限体系。

安全策略。

默认规则。

系统级配置。

System Settings。

不是简单的设置页面。

而是整个 Factory 的 Governance Center（治理中心）。

# 二、System Settings 定位（Position）

System Settings。

不是：

配置页面。

也不是：

系统参数。

System Settings。

是整个 Factory 的 Governance Center。

帮助 Operator。

统一管理。

统一约束。

统一规范。

整个 Factory 的运行规则。
